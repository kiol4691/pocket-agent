Place the 5 prebuilt proroot libraries from the coderredlab/proroot release into this directory:

- libproroot.so
- libproroot-runtime.so
- libproroot-linker.so
- libproroot-bridge.so
- libproroot-stub-loader.so

These are arm64-v8a only (proroot requires Android 8.0+ / arm64). Rebuild the APK after adding them.
See README.md at the project root for details.
